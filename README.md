# SmokeSignal has been renamed to FireSquire

Same pre-reboot GO / CAUTION / NO-GO advisory for Unraid, same read-only engine — new
medieval-flavored name to match the rest of the house.

**If you have SmokeSignal installed:** Unraid will offer this repo's plugin as an update
(a no-op — same package, just a notice). Read it, then uninstall SmokeSignal and install
FireSquire instead:

**https://github.com/junkerderprovinz/firesquire**

This repo exists only so that an already-installed SmokeSignal plugin's normal
update-check can still reach a migration notice (`raw.githubusercontent.com` does not
redirect for a renamed GitHub repo). It receives no further development.
